# Crema & Crust — ゲームデザイン

## コンセプト

個人経営の小さなピッツェリア兼エスプレッソカフェを舞台にした、
**のほほんと暇つぶしできる、落ち着いたクラフトゲーム**。

プレイヤーは店主。ピザを焼き、エスプレッソを淹れ、ときどきふらっと来る常連客と
ゆるく交流する。急かされることは一切ない。閉店時間もノルマもない。

## デザインピラー(判断に迷ったらここに戻る)

1. **工程そのものが楽しい**
   ピザ作り(こねる・塗る・のせる・焼く)とエスプレッソ(挽く・タンピング・抽出・注ぐ)の
   一つひとつの工程を、手触りのあるインタラクションとして丁寧に作る。
   結果より過程。効率化・自動化は導入しない。

2. **失敗が存在しない**
   どんな焼き加減も、どんな抽出も「そういう一杯・一枚」として肯定的に受け止められる。
   よく焼けたピザは「ナポリの下町風」、長めの抽出は「ゆったりルンゴ」。
   減点・ゲームオーバー・やり直し強制は作らない。

3. **時間に追われない**
   タイマー・制限時間・スコアアタック・行列は作らない。
   お客さんは待つのが苦にならない人しか来ない。放置してもデメリットなし。
   窯の火加減もリアルタイム強制ではなく、プレイヤーが見たいだけ眺めて、
   好きなタイミングで取り出す。

4. **居心地のよさが報酬**
   進行報酬は「新しい豆・トッピング・常連さんとの何気ない会話」など、
   遊びの幅と雰囲気が増えるものに限る。通貨・経営数値・売上目標は導入しない。

## やらないことリスト

- 制限時間、コンボ、スコア、ランキング
- 客の不機嫌・クレーム・帰ってしまうペナルティ
- 所持金・売上・経営シミュレーション要素
- ガチャ・スタミナ・デイリーノルマ
- 失敗判定(焦げ=失敗、抽出過多=失敗、のような扱い)

## コアループ

```
気が向いたら…
  ├─ ピザを焼く      → レシピノートに記録される
  ├─ エスプレッソを淹れる → レシピノートに記録される
  ├─ お客さんに出す    → 一言会話 + 「ありがとうカード」がたまる
  └─ 何もしない      → 店の時間がゆっくり流れるのを眺める
「ありがとうカード」や作った回数で、新しい素材・豆がゆるやかに解放される
```

## トーン & ビジュアル方針

- 温かみのあるフラットデザイン(CSS/SVG ベース)。クリーム色・テラコッタ・深緑が基調。
- 時間帯(朝→昼→夕方→夜)で店の光がゆっくり移ろう。演出のみで、ゲームに影響しない。
- テキストは日本語。ひらがな多めの柔らかい文体。「!」より「…」「〜」を好む。
- 効果音・BGM は MVP では実装しない(将来、環境音を検討)。
