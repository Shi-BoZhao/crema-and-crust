# Crema & Crust — メカニクス仕様(MVP)

MVP で実装する画面・工程・データの具体仕様。game-design.md のピラーに従う。

## 画面構成

```
[店内 (ホーム)] ── ピザ窯をタップ ──→ [ピザ作り]
      │
      ├──── エスプレッソマシンをタップ ──→ [エスプレッソ]
      │
      ├──── カウンターのお客さんをタップ ──→ [提供 & 会話]
      │
      └──── ノートをタップ ──→ [レシピノート(作った記録)]
```

店内はいつでも戻れるホーム画面。時間帯によって背景の色調が変わる。

## ピザ作り(4工程)

各工程は「次へ」で自由に進む。戻るのも自由。時間制限なし。

1. **生地をのばす**: 生地をクリック/タップするたびに少しずつ広がる。
   何回押してもよい。広さで「厚め / ふつう / 薄め」の食感が決まる(全部おいしい)。
2. **ソースを塗る**: ドラッグで塗る。塗り具合で「トマト薄め / たっぷり」など表現が変わる。
   白ピザ(ソースなし)も選べる。
3. **トッピング**: パレットから選んで好きな位置に置く。個数制限なし。取り除きも自由。
   初期素材: モッツァレラ、バジル、マッシュルーム、オリーブ。
   解放素材: 生ハム、アンチョビ、ゴルゴンゾーラ、はちみつ など。
4. **窯で焼く**: 窯の中のピザを眺める。焼き色がゆっくり変わっていく。
   好きなタイミングで「取り出す」。
   - 浅め → 「もっちり白焼き」 / ほどよく → 「こんがり」 / 長め → 「ナポリの下町風(よく焼き)」
   - どれも成功。表現が変わるだけ。放置してもリアルタイムでは進まない
     (画面を見ている間だけ焼ける = 席を外しても焦げない)。

完成すると命名された一枚(例:「バジルともっちり白焼きのピザ」)がノートに記録される。

## エスプレッソ(4工程)

1. **豆を選ぶ・挽く**: 豆を選び、ミルをくるくる回す(ドラッグ or 連打)。
   挽いた量が見た目でたまる。細かさの選択(粗め/ふつう/細かめ)で味の表現が変わる。
2. **タンピング**: ポルタフィルターを押して押し固める。押した回数で「やさしめ/しっかり」。
3. **抽出**: レバーを押すと抽出が始まり、カップに液面がゆっくり上がる。
   好きなところで止める。短め=リストレット、ふつう=エスプレッソ、長め=ルンゴ。
   クレマの表現(泡の色)が抽出と豆で変わる。
4. **仕上げ**: そのまま出す / お湯を足してアメリカーノ / (解放後)ミルクでカプチーノ。
   カプチーノはカップを傾けてラテアート風の模様がランダムに出る(結果は常に肯定)。

初期豆: ハウスブレンド。解放豆: エチオピア(華やか)、ブラジル(香ばしい)、深煎り。

## お客さん

- カウンターに 0〜1 人がゆったり出入りする。来ないときは来ない。
- タップすると一言つぶやく(注文というより「気分」)。
  例:「今日はあったかいものが飲みたい気分…」
- 何を出しても喜ぶ。気分に合っていると会話が少し特別になる。合っていなくても
  「へえ、これもいいね」と肯定される。
- 提供すると「ありがとうカード」が 1 枚たまる。
- MVP の常連: 3 人(散歩途中のおばあちゃん、原稿中の作家さん、部活帰りの学生)。
  それぞれ口調と好みの傾向がある。

## 解放(アンロック)

「ありがとうカード」の累計でゆるやかに解放。テンポ重視で閾値は低めに。

| カード累計 | 解放 |
|---|---|
| 2 | 豆: ブラジル |
| 4 | トッピング: 生ハム |
| 6 | ミルク(カプチーノ) |
| 9 | 豆: エチオピア |
| 12 | トッピング: ゴルゴンゾーラ + はちみつ |
| 15 | 豆: 深煎り / トッピング: アンチョビ |

解放時は「新しい豆が届きました…」と静かに知らせる。未解放要素は「?」で見せない
(ノルマ感を出さないため、一覧で煽らない)。

## レシピノート

- 作ったピザ・カップが名前つきで時系列に並ぶだけの、眺める図鑑。
- コンプリート率や達成度は表示しない。

## セーブ

- localStorage に自動保存(ノート、カード数、解放状態)。
- セーブスロットや手動セーブは作らない。

## 時間帯

- 実時刻から 朝(5-10)/昼(10-16)/夕(16-19)/夜(19-5) を判定し、店内の色調に反映。
- ゲームプレイへの影響はゼロ。
