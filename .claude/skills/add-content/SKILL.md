# ゲーム内コンテンツ追加の手順

トッピング・コーヒー豆・常連客・会話文言はすべて `src/data/` に集約されている。
コードロジックには触らずデータ追加だけで済むのが正しい状態。ロジック変更が
必要になったら設計の匂いを疑うこと。

## 手順

1. `docs/game-design.md` のトーン方針を読み、追加コンテンツが
   「落ち着いた・肯定的・ノルマ感なし」に合うか確認する。
2. 対象ファイルに追記する:
   - トッピング → `src/data/toppings.ts`
   - コーヒー豆 → `src/data/beans.ts`
   - 常連客・会話 → `src/data/customers.ts`
3. 解放条件に組み込む場合は `src/game/unlocks.ts` の解放テーブルに追記する。
   閾値は既存の間隔(2〜3 カードごと)を守り、詰め込みすぎない。
4. 文言チェックリスト:
   - 日本語。ひらがな多め。「!」より「…」「〜」。
   - どの結果・組み合わせでも否定的な表現にならない。
   - 煽り(「今だけ」「あと◯個で」)を入れない。
5. `npm run test` を実行。解放テーブルを変えた場合はテストの期待値も更新する。

## 例(トッピング追加)

```ts
// src/data/toppings.ts
{ id: 'artichoke', name: 'アーティチョーク', color: '#8a9a5b', shape: 'leaf' },
```
